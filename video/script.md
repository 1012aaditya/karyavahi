# Karyavahi: demo video narration (3:00)

What the hackathon asks the video to show, and where it is:

| Requirement | Blocks |
|---|---|
| The challenge, and how Karyavahi addresses it | 01, 02 |
| A walkthrough of the user interface | 03, 04, 05 |
| Key features, each tied to the challenge | 03–05 (called out on screen) |
| Features that make it easy for the intended users | 04 (field: Hindi, listen, speak, offline, WhatsApp), 03 (⌘K, one-tap approval, plain-language Claude) |
| Fallback if the live link fails | the whole walkthrough runs on the real live site |

Judges stop at 3:00, so everything required is inside it. Read at a calm pace, about 130 words a
minute. Pause briefly at each `/`. Each block starts at the time shown; if you finish early, wait.

How to record: phone voice-memo app, quiet room, phone about 20 cm away. One take, or one clip
per block named 01.m4a … 07.m4a.

---

### 01 · The challenge (0:00 – 0:20)
In a block office in Rampur, / a dashboard turns red: / Class 3 subtraction has fallen eighteen points. /
And then… / nothing happens. /
Officers have data, / but every system stops at the alert. / No owner, / no deadline, / no proof, /
and no one checks whether children learned more.

### 02 · Our answer (0:20 – 0:32)
Karyavahi turns every learning drop into a case: / flag, diagnose, plan, approve, act, verify. /
And a case closes only when the next assessment shows / children learned more.

### 03 · The officer's view (0:32 – 1:15)
The block officer starts on a command centre, / not a spreadsheet: / their own area on a real map, / and what needs them today. /
Anything is one search away, / or they can just ask Claude. /
Here is the case: / the drop, / the schools driving it, / and the conditions behind it. /
Claude explains it in plain words, / and every figure it writes is checked against the records. /
It suggests a plan from an evidence library, / with real costs. /
But the officer decides, / and a second officer approves, / in one tap. /
Every task gets an owner / and a deadline.

### 04 · Easy for people in the field (1:15 – 1:50)
For headmasters and field staff, / it works the way they already work. /
It opens in Hindi. / They can listen to their day / instead of reading it, / and speak a note / instead of typing. /
No signal? / Proof is saved on the phone, / and sent when the network returns, / with the location checked. /
And they don't even need the app: / on WhatsApp, / tasks arrive, / a reply marks them done, / and a photo becomes proof.

### 05 · Proof, then results (1:50 – 2:10)
Proof is checked by someone other than the person who did the work. /
When the next round arrives, / Karyavahi compares plan schools with similar schools, / and asks: / did it work? /
If not, / the case reopens. / And the Action Taken Report / writes itself.

### 06 · Why you can trust it (2:10 – 2:35)
Claude only drafts and explains, / from records the user is allowed to see, / always cited. /
The decisions are made by people, / and every change goes into a tamper-evident audit trail. /
Schools, costs and district figures come from real public data. /
And it's tested end to end: / every page, / every role.

### 07 · Next, and close (2:35 – 3:00)
Next: / a pilot in one district, / with the state's own data, / then state-wide. /
Karyavahi. / AI drafts. / Officers decide. / The ledger proves. /
Close a case / only when children learn more.
