# Karyavahi demo: narration with exact timestamps

Read each line so it **starts at the time on the left**. The words are burned into the video as captions, so read them exactly as written.
Play `out/karyavahi-demo-muted.mp4` on your laptop and read along into your phone's voice-memo app.

**Two ways to record:**
- **Easiest:** one take for the whole 3 minutes while the muted video plays. Save it as `public/audio/user/full.m4a`.
- **Or:** one clip per block (01 to 07). Start each clip at the block's start time; it must end before the next block starts. Save as `public/audio/user/01.m4a` … `07.m4a`.

Gaps between blocks (for example 0:18.8 to 0:20.3) are deliberate pauses: stay silent.
